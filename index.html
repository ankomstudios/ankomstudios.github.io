Creation

WannaSmile was Created in September 2025. and the latest version is available at Ankom Studios!

Purpose & Use

The purpose of WannaSmile is to provide a distributor network for assets in a expressive web service environment. Usage of WannaSmile includes browsing the catalogue, Exploring projects, And reviewing based on user experience.

Version History

Wannasmile has undergone several updates since its creation, with each version bringing new features and improvements to enhance the user experience.
